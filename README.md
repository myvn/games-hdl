# 魂斗罗 · 十关全程（H5 横版射击）

致敬 KONAMI 1987 经典《魂斗罗》(Contra) 的纯前端复刻。
React + Vite + Canvas 2D，全部美术与音效均由代码程序化生成，**零图片、零音频资源**。

![风格](https://img.shields.io/badge/街机-1987-orange)
![纯前端](https://img.shields.io/badge/零资源程序化生成-green)
![移动端](https://img.shields.io/badge/手机触屏-支持-blue)

## 玩法特性

- 🕹️ **八方向射击**：上射 / 斜上 / 下射 / 卧倒射击，空中翻滚
- 🌪️ **5 种武器，Q 键自由轮换**：散弹枪(扇形7发) → 追踪导弹(自动锁定) → 重机枪(三连发) → 激光炮(贯穿) → 突击步枪
- 🛡️ **L 键举盾 + 自动出刀**：格挡正面子弹，敌人贴身自动斩击（可破 Boss 部件）
-  **二段跳**、↓+跳 穿越吊桥、子弹对消（打飞敌方弹幕）
-  **10 大关卡 + 10 位不同机制的首领**（详见下表）
- ♾️ 无限生命 · 关卡进度自动衔接 · 可跳关

## 操作

| 按键 | 功能 |
| --- | --- |
| `← →` / `A D` | 移动 |
| `↑ ↓` / `W S` | 瞄准（上射 / 卧倒·下射） |
| `K` / `X` / `Shift` | 跳跃（空中可再跳一次） |
| `J` / `Z` / `空格` | 射击 |
| `L` / `C` | 举盾格挡 + 贴身出刀 |
| `Q` | 切换武器 |
| `P` / `Esc` | 暂停 |
| `M` | 静音 |

手机端自带虚拟摇杆（八方向）+ A/B/L/Q 四个按钮。

## 本地运行

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 生产构建（产物为单文件 dist/index.html，可直接双击打开）
npm run build
```

## 项目结构

```
src/
├── game/
│   ├── types.ts     # 常量与类型定义
│   ├── level.ts     # 10 关数据（3 手工关 + 7 程序化生成）
│   ├── game.ts      # 主引擎：物理 / AI / 武器 / 关卡流程
│   ├── boss.ts      # 10 位首领的行为与像素绘制
│   ├── sprites.ts   # 主角 / 敌人 / 地形 / 10 种场景背景
│   └── audio.ts     # WebAudio 8-bit 音效合成
├── components/
│   └── TouchControls.tsx  # 手机触屏控制
└── App.tsx          # 界面：选关 / 武器栏 / 首领图鉴 / 结算
```
